# Loop Visualizer

## Overview
The Loop Visualizer is an advanced tool for analyzing and visualizing loops in code. It detects loops in various programming languages and provides real-time visualization of loop iterations.

## Supported Languages
- JavaScript (.js)
- Python (.py)
- Java (.java)
- C++ (.cpp)
- C (.c)

## Features
1. **Code Analysis**: Automatically detects loops in uploaded code files
2. **Loop Detection**: Identifies for loops, while loops, and do-while loops
3. **Variable Tracking**: Extracts and tracks loop variables (i, j, sum, etc.)
4. **Real-time Visualization**: Animates loop iterations with adjustable speed
5. **Actual Output Simulation**: Shows real console output as it would appear during execution
6. **Step-by-Step Navigation**: Navigate forward/backward through iterations
7. **Dynamic Calculations**: Computes actual values (factorials, sums, products) based on loop variables
8. **Professional UI**: Clean, modern interface with intuitive controls
9. **Rich Visualization**: Color-coded elements, icons, and progress indicators
10. **Analysis Output**: Provides detailed analysis of detected loops

## How to Use

### 1. Upload Code
- Click "Choose a file" to upload a code file
- Supported formats: .js, .py, .java, .cpp, .c
- The code will be displayed in the editor

### 2. Analyze Code
- Click "Analyze Code" to process the uploaded file
- The tool will detect all loops in the code
- Detected loops will appear in the "Detected Loops" section

### 3. Select Loop
- Click on any detected loop to visualize its iterations
- The loop's variables will be identified and tracked

### 4. Visualize Iterations
- Use the Play/Pause button to start/stop the animation
- Use the Stop button to reset the visualization
- Adjust speed using the speed selector (0.5x, 1x, 2x, 4x)
- Watch as variable values change in real-time

### 5. View Details
- The iteration table shows all variable values for each iteration
- The analysis output provides detailed information about the code
